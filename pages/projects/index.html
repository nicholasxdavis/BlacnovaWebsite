Game development

Game development at Blacnova Studio

Our Las Cruces studio builds original games and prototypes in Lua and LÖVE. These projects explore procedural worlds, character behavior, and the systems that make a simulation feel alive.

Pixelvida

A 2D survival sandbox built from Lua and Love2D primitives.

Pixelvida is the studio's flagship internal game project: a 2D survival sandbox authored entirely in Lua on Love2D. The team built the core game loop and world simulation directly, with systems for combat, farming, weather, and non-player characters.

The runtime drives a day and night cycle, weather, zombie combat AI, crop farming, and crafting for structures such as campfires and chests. A hoverboard handles traversal. The map is generated at runtime rather than authored as a static scene.

Zero image assets

Pixelvida was designed as a rendering experiment first. Love2D gave the team a thin, controllable layer over the GPU and the update tick.

There are no sprite sheets in the pipeline. Characters, items, and terrain are assembled by drawing geometric primitives (rectangles, circles) onto canvases, then promoting those canvases to pixel-art textures for animation and collision.

That constraint forced sharper decisions around performance budgets, memory layout, and procedural generation. When the primitives started walking, the architecture had already earned its keep.

Character animation from primitives, no sprite file.

Pixelvida Community

Top-down systems in a shared town simulation.

The side-view Love2D build validated core systems. Pixelvida Community scales those ideas into a top-down town: armory, farming plots, a day clock, campfires, and hostile AI that keeps pressure on the player.

The team treats it as a live systems lab for inventory, shops, crate keys, and spatial layout that reads as a place rather than a tile grid. Screenshots below are the runtime view, not the editor.

Block Blast

A Love2D packing puzzle compiled for the browser.

Block Blast is a compact packing loop: place pieces, clear lines, chase score. Built in Love2D and exported to the web so sessions start with no install step.

An in-game shop covers row blasts, column blasts, color wipes, and related power-ups. The scope stays intentionally smaller than Pixelvida so the team can ship a complete loop, gather play feedback, and refine feel without a long production tail.
