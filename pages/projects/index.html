Game development

Built in the hours after client work

Websites pay the lights. Games are where I push the stack until it breaks, then put it back together. Lua, Love2D, and a lot of late nights in Las Cruces.

Pixelvida

First game. First time with Lua. First time with no safety net.

Pixelvida is my first game. A 2D survival sandbox built completely from scratch in Lua with Love2D. It was a crash course in game loop architecture and keeping a world in memory without cheating.

The engine runs a day and night cycle, weather, mob AI for fighting off zombies, a farming system for crops, and crafting for structures like campfires and chests. There is a hoverboard for getting around. The world is generated at runtime.

Zero image files

For a stretch of months I poured spare time into Pixelvida, the first project that felt like mine. Love2D is amazing for this.

The strangest part is also the point. There are no sprite sheets to lean on. Every character, item, and piece of terrain is built by rendering raw geometric primitives (rectangles, circles) onto canvases, then treating those canvases as pixel-art textures.

Pixelvida was an experiment first and a game second. I wanted to step outside the comfort of shipping websites. Learning Lua and procedural generation without an asset pack forced better thinking about performance, memory, and architecture. Steep curve. Watching those shapes start walking made it worth it.

Pixelvida Community

Same ideas, top-down, with other people in the town.

The Love2D build taught the systems. Pixelvida Community is the larger world: a top-down town with an armory, farming plots, a day clock, campfires, and zombies that do not wait for you to be ready.

It is still a learning lab. Inventory, shops, a mystery armory, crate keys, and a map that has to feel like a place instead of a grid. The screenshots below are the game view, not the editor.

Block Blast

A Love2D puzzle you can play in the browser.

Block Blast is a packing puzzle: drop pieces, clear lines, chase a score. Built in Love2D and shipped to the web so it runs without installing anything.

There is a shop for row blasts, column blasts, color wipes, and a few extras. It is smaller than Pixelvida on purpose. Finish a loop, put it in front of people, learn what feels cheap.

Pixel Prototypes

A Lua lab for the pieces underneath the games.

Pixel Prototypes is not a game you boot up. It is the workshop: weapons, ammo, shields, consumables, character and armor, world pieces. Small Love2D programs that prove a system before it lands in Pixelvida.

That is how the hoverboard, the chest, and the zombie AI got honest. Break the part in isolation, then drop it into the world.
